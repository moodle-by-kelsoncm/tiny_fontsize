Instalação
==========

Requisitos
----------

- **Moodle**: 4.1 ou superior (versão mínima exigida `2022112800`)
- **PHP**: 8.0 ou superior suportado pela sua versão do Moodle

Procedimento de Instalação
--------------------------

1. Acesse o diretório de plugins do TinyMCE na sua instalação Moodle:

   .. code-block:: bash

      cd /caminho/do/moodle/lib/editor/tiny/plugins

2. Clone o repositório nomeando a pasta como `fontsize`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/tiny_fontsize.git fontsize

3. Acesse **Administração do site > Notificações** no Moodle para concluir a instalação do banco de dados.
