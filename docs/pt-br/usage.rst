Guia de Uso
===========

Alterando o Tamanho do Texto
----------------------------

1. Selecione o texto desejado dentro do editor TinyMCE.
2. Clique no seletor **Font Size** na barra de ferramentas ou acesse **Format > Font size**.
3. Escolha a dimensão desejada para aplicar imediatamente a alteração de tamanho ao texto selecionado.
