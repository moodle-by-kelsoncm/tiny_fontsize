Visão Geral - moodle-tiny_fontsize
==================================

O **moodle-tiny_fontsize** é um plugin para o editor TinyMCE do Moodle que adiciona um seletor de tamanho de fonte à barra de ferramentas e ao menu **Format**, permitindo redimensionar o texto selecionado com facilidade.

Recursos Principais
-------------------

- **Botão na Barra de Ferramentas**: Seleção prática de tamanhos de fonte no editor.
- **Entrada no Menu Format**: Acesso através dos menus convencionais de formatação.
- **Unidades Customizáveis**: Suporte para unidades CSS flexíveis (`pt`, `px`, `em`, `rem` ou `%`).
- **Lista Configurável**: Tamanhos de fonte gerenciados diretamente pelo painel administrativo.
- **Ocultação Automática**: Se menos de dois tamanhos forem configurados, o seletor é ocultado automaticamente.
