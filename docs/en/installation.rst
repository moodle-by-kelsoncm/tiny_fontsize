Installation
============

Requirements
------------

- **Moodle**: 4.1 or higher (minimum required version `2022112800`)
- **PHP**: 8.0 or higher supported by your Moodle release

Installation Procedure
----------------------

1. Access the TinyMCE plugins directory in your Moodle installation:

   .. code-block:: bash

      cd /path/to/moodle/lib/editor/tiny/plugins

2. Clone the repository naming the folder `fontsize`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/tiny_fontsize.git fontsize

3. Access **Site administration > Notifications** in Moodle to complete the database installation.
