Configuration
=============

Plugin Settings
---------------

Go to: **Site administration > Plugins > Text editors > TinyMCE editor > Font size**.

Available Options:

- **Font sizes**: List of sizes offered in the selector (one per line), for example::

     8
     10
     12
     14
     18
     24
     36

- **Font size unit**: The CSS unit applied to the values (`pt`, `px`, `em`, `rem`, or `%`).
