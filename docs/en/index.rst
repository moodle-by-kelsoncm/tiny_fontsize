Overview - moodle-tiny_fontsize
=================================

**moodle-tiny_fontsize** is a plugin for Moodle's TinyMCE editor that adds a font size selector to the toolbar and the **Format** menu, enabling easy resizing of selected text.

Key Features
------------

- **Toolbar Button**: Convenient font size selection directly in the editor.
- **Format Menu Entry**: Accessible through standard formatting menus.
- **Customizable Units**: Support for versatile CSS units (`pt`, `px`, `em`, `rem`, or `%`).
- **Configurable List**: Font sizes managed directly through the administration panel.
- **Auto Hiding**: If fewer than two font sizes are configured, the selector is hidden automatically.
